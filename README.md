# Praia Clube — Proposta de Redesign da Home

Protótipo navegável da nova home de [praiaclube.org.br](https://praiaclube.org.br), criado para a apresentação da reestruturação visual do portal.

## Como publicar no GitHub Pages

1. Crie um repositório (ex.: `praia-clube-proposta`) e envie estes arquivos.
2. No repositório: **Settings → Pages → Source: Deploy from a branch → Branch: `main` / (root) → Save**.
3. Em ~1 minuto a página estará em `https://SEU-USUARIO.github.io/praia-clube-proposta/`.

O protótipo é um único `index.html` autocontido — CSS e JS embutidos. Fotos, logos e fontes (Google Fonts) carregam da internet, então a página deve ser vista online.

## Conteúdo da proposta

- Design system: amarelo `#FFDC0E` + preto `#0D0D0F`, tipografia Archivo/Inter, cards com raio 20px
- Nova arquitetura: hero → jogos → publicidade → equipes → conquistas → agenda → notícias → lazer → sócio/patrocinador → app → FAQ → rodapé
- Responsivo (desktop, tablet e mobile), com carrossel de anunciantes, FAQ em sanfona e animações de entrada
